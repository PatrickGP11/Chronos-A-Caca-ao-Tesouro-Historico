# ⏳ Chronos: A Caça ao Tesouro Histórico

Chronos é uma plataforma educacional gamificada projetada para transformar o aprendizado de história em uma jornada interativa. Através de uma linha do tempo dinâmica, os usuários exploram dossiês detalhados sobre os maiores conflitos e eventos da humanidade, enfrentando desafios para conquistar medalhas e avançar nas eras.

## 🚀 Funcionalidades

Linha do Tempo Progressiva: Eventos são desbloqueados à medida que o jogador domina o nível anterior.

Dossiês Detalhados: Cada evento é dividido em quatro abas fundamentais: Contexto, Conflito, Desfecho e Curiosidade.

Trava Pedagógica de Leitura: O desafio final só é liberado após o usuário explorar todas as informações do dossiê.

Sistema de Quiz e Medalhas: * 🥇 Ouro: Acerto na primeira tentativa.

🥈 Prata: Acerto na segunda tentativa.

🥉 Bronze: Acerto após três ou mais tentativas.

Temas Dinâmicos: A interface muda de cor e estilo visual de acordo com a era histórica (Antiguidade, Idade Média, Moderna, etc.).

Persistência de Dados: O progresso e as medalhas são salvos automaticamente no navegador (localStorage).

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web fundamentais (Vanilla Tech Stack) para garantir performance e simplicidade:

HTML5: Estrutura semântica dos elementos e do modal.

CSS3: Estilização avançada, animações de entrada (keyframes), layout responsivo e variáveis CSS para troca de temas.

JavaScript (ES6+): Lógica de progressão, manipulação de DOM, sistema de filtragem de leitura (usando Set) e gerenciamento de estado do quiz.

Google Fonts: Utilização das fontes Cinzel (para títulos históricos) e Roboto Slab (para leitura técnica).

## 🎮 Como Jogar

Explorar: Clique no evento desbloqueado na linha do tempo.

Investigar: Leia atentamente as quatro abas de conteúdo. O botão de desafio será liberado apenas após a leitura completa.

Desafiar: Responda à pergunta sobre o evento.

Conquistar: Receba sua medalha e veja o próximo marco histórico aparecer na sua tela.

## 📂 Estrutura do Projeto

├── index.html      # Estrutura principal e containers do modal
├── style.css       # Estilização, temas de cores e responsividade
└── script.js      # Banco de dados de história e motor do jogo

## ⚙️ Instalação e Execução

Como o projeto utiliza apenas tecnologias front-end puras, não é necessário instalar dependências.

Clone o repositório: git clone https://github.com/seu-usuario/chronos-history-hunt.git

Navegue até a pasta do projeto e abra o arquivo index.html em qualquer navegador moderno.
